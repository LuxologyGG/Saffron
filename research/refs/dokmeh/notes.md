## What's worth re-skinning for a Torrance Persian deli
1. **Abstracted shamse (sun-medallion) blob** — Persian rosette geometry as a giant flat brand shape holding the logo/headline. For the deli: a saffron-yellow shamse containing "fresh today" or the logo, over a deep spice-toned ground.
2. **Grain/noise over flat saturated color** — Tehran-poster texture treatment; instantly Persian-contemporary without any literal tilework.
3. **Two-layer roll-up hover text** (MoveScaleUpInitial/End keyframes, translateY 100%→0, ~0.4–0.6s) — cheap, premium-feeling micro-interaction for menu/nav items.
4. **Farsi as UI element** — a فارسی toggle / Farsi micro-labels beside Latin; bilingual UI signals authenticity.
5. Rounded-pill chrome (56–120px radii) + tight-tracked grotesque display type — modernizes the heritage cues so the deli doesn't read as a museum.

Caution: Dokmeh's blue/yellow clash is agency-loud; for a deli, keep the geometry+grain language but swap to food-credible hues (saffron, pistachio, pomegranate, sangak-crust brown).
