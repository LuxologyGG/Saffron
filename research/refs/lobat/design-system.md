# Lo'bat (lobataccessories.com) — Design System Extraction

Awwwards-nominated Persian accessories brand ("Lo'bat" = old Persian compliment, "beautiful lady").
Captured 2026-07-18, homepage, desktop 1440 + mobile 390. WordPress/WooCommerce + Swiper + Plyr video.

## Palette
- Near-black ink: `#212529` (rgb 33,37,41) and `#000` — dominant text/ground
- Cream/antique white: `antiquewhite` `#FAEBD7` — hand-script headline color on dark photo
- Dusty mauve-pink: `#CDB0C2` (rgb 205,176,194) — soft feminine accent
- Sand/khaki: `#CABFA5` (rgb 202,191,165) — warm neutral accent
- Palette reads as muted film-photography tones; color arrives via imagery, UI is monochrome.

## Type
- **"Roses Please"** — hand-lettered script for hero headline "Be Unique, Be Inspired": loose, calligraphy-adjacent strokes over photography (the Persian-calligraphic gesture rendered as Latin script).
- **DM Mono (monospace)** — nav, labels, product names; wide-set, technical counterpoint to the script.
- Farsi-script logotype: the wordmark is drawn in actual Perso-Arabic script with a small Latin "Lobat" annotation beneath — bilingual mark.
- Text-transform capitalize only; no aggressive uppercase.

## Spacing/grid
- Full-bleed hero photography, headline script overlapping bottom-left, logo centered breaking the header line.
- Product grid: standard 3–4 col WooCommerce cards, generous white space.

## Radii
- `180px` (circular/pill elements), `10px` (cards).

## Motion
- Swiper carousels (swiper-preloader-spin keyframe), Plyr video player (plyr-fade-in, plyr-progress), Bootstrap spinners; fa-spin. Standard library motion, ~0.3–1s linear/ease — nothing bespoke.
- Intro video ("The Lo'bat Concept") is the centerpiece motion asset.

## Persian motifs worth noting
- Perso-Arabic calligraphic logotype paired with a Latin annotation (bilingual lockup).
- Handwritten script headline as ornament over photography.
- Product names use Persian words (Takhmeh, Sarv = cypress — a classic Persian garden/miniature motif).
- Muted analog-film color grading evoking Iranian photography.
